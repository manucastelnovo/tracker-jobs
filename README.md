# 📋 Trackeador de Postulaciones

Aplicación web para rastrear tus postulaciones de empleo diarias.

## Características

- 📊 Contador de postulaciones por día
- 🎯 Control de meta diaria (20 postulaciones)
- 📅 Calendario visual con historial de 90 días
- 💾 Almacenamiento local (sin servidor)
- 🌙 Soporte light/dark mode

## Uso

Simplemente abrí `index.html` en tu navegador. Los datos se guardan automáticamente en tu navegador.

## Requisitos

Ninguno — funciona con cualquier navegador moderno.
